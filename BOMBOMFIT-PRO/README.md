# BOMBOM fit — Android LOCAL

Versão preparada para funcionar **sem Supabase e sem banco externo**.

## Armazenamento
- Dados do perfil, água, passos, nutrição e treinos: armazenamento local do aparelho.
- Credenciais locais: armazenamento seguro do aparelho.
- Não exige conta Supabase, servidor ou pagamento de backend.

## GitHub
Envie o conteúdo desta pasta para a raiz do repositório `BOMBOMFIT-PRO`, na branch `principal`.
Não envie a pasta antiga `BOMBOMFIT-FINAL`.

Depois execute **Actions → Build BOMBOM fit → Run workflow → principal**.
O workflow gera APK e AAB.
